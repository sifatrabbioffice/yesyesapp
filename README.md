# Yes Yes App

একটি সিম্পল ক্লিক করার গেম যা Windows EXE এবং iOS IPA উভয় প্ল্যাটফর্মে চলে।

## ফিচার

- **স্টার্ট স্ক্রিন**: হোয়াইট ব্যাকগ্রাউন্ড, মাঝে "Click To Start" বাটন
- **গেম স্ক্রিন**: কালো ব্যাকগ্রাউন্ড, মাঝে লাল বৃত্ত "Start" বাটন সহ
- **সম্পন্ন স্ক্রিন**: হোয়াইট ব্যাকগ্রাউন্ড, "OK BYE" মেসেজ
- লুপ পুনরাবৃত্তি হয়
